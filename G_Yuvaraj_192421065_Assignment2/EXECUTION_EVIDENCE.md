# Execution evidence index

- Each `TaskXX/output.txt` contains the captured standard output for its task.
- `Task06/timing_O0.txt` and `Task06/timing_O2.txt` contain timing experiment output.
- `Task02/compiler_warning.txt` contains the compiler warning for the deliberately unsafe example.
- `BUILD_AND_TEST_LOG.txt` contains compiler and execution logs from the build run.

These are text logs, not screenshots. Capture screenshots on your own machine if required by your course.
